# Workforce & HR Analytics Dashboard

An end-to-end HR analytics project analyzing employee attrition and workforce characteristics using SQL, Python, and Microsoft Power BI.

The project demonstrates a complete analytics workflow from raw data quality checks and SQL-based transformation to exploratory data analysis and an interactive Power BI dashboard.

> **Dataset note:** This project uses the IBM HR Analytics Employee Attrition & Performance dataset, which is a fictional/synthetic dataset commonly used for analytics practice. The results should not be interpreted as actual IBM workforce statistics.

---

## Project Overview

The objective of this project is to analyze employee attrition patterns and identify workforce segments associated with higher observed attrition rates.

The analysis focuses on factors such as:

- Department
- Job Role
- Job Level
- Overtime
- Age Group
- Work-Life Balance
- Job Satisfaction
- Business Travel
- Monthly Income
- Years at Company
- Total Working Years
- Distance From Home

The final output is an interactive Power BI dashboard supported by SQL analysis and Python exploratory data analysis.
